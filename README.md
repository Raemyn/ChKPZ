# Мои смены — Календарь смен и учёт выработки деталей

Адаптивное клиентское веб-приложение для личного учёта рабочих смен, подсчёта выработки изготовленных деталей и автоматического расчёта заработка.

Приложение работает полностью в браузере пользователя, сохраняет все данные в `localStorage` и не требует сервера или базы данных. Полностью подготовлено к публикации на **GitHub Pages**.

---

## Возможности

* 📅 **Автоматический расчёт смен по 8-дневному циклу**:
  1. Ночная
  2. Ночная
  3. Отсыпной
  4. Выходной
  5. Дневная
  6. Дневная
  7. Выходной
  8. Выходной
  *(Точка отсчёта: 30 сентября 2026 года = Ночная смена).*
* ⚙️ **Точный математический алгоритм**: корректно работает для любых прошедших и будущих месяцев и лет, защищён от проблем с часовыми поясами (UTC-вычисления).
* 💰 **Автоматический расчёт заработка**:
  * Формула: `сумма = количество деталей × 16 ₽`.
  * Ставка вынесена в константу (`DEFAULT_PRICE_PER_ITEM = 16`) и может быть изменена в настройках.
  * Числа красиво отформатированы по стандарту `ru-RU` (`4 800 ₽`, `42 400 ₽`).
* ⚠️ **Пометка сомнительных дней**:
  * Флаг «Нужно проверить» (если выработка указана приблизительно).
  * Наглядный маркер ⚠️ в календаре.
  * Интерактивный список таких дней в сводке месяца с быстрым переходом к редактированию.
* 📝 **Заметки к смене**: возможность сохранить текстовый комментарий для любого дня (поломка оборудования, номер партии и т.д.).
* 📊 **Подробный расчёт месяца**:
  * Общее количество учтённых смен.
  * Всего изготовлено деталей.
  * Итоговая сумма заработка.
  * Раздельная детализация по дневным, ночным и сверхурочным сменам.
  * Возможность скопировать текстовый отчёт в один клик.
* 📱 **Полная адаптивность и наглядная палитра смен**:
  * ☀️ **Дневная смена** — тёплый оранжевый оттенок со значком солнца.
  * 🌙 **Ночная смена** — насыщенный синий цвет со значком полумесяца.
  * 🛌 **Отсыпной день** — глубокий тёмно-зелёный оттенок (отдых после ночи).
  * 🌿 **Выходной день** — отчётливый зелёный цвет с рамкой, который больше не сливается с тёмным фоном приложения.
* 💾 **Надёжное хранение в localStorage**: данные не пропадают при перезагрузке страницы или смене месяца. Доступен экспорт и импорт резервной копии (JSON).

## Руководство по запуску и публикации на GitHub Pages

### 1. Установка зависимостей

Убедитесь, что у вас установлен Node.js (рекомендуется версия 18 или новее). В папке проекта выполните:

```bash
npm install
```

### 2. Запуск проекта локально для разработки

```bash
npm run dev
```

В консоли появится локальный адрес (обычно `http://localhost:3000` или `http://localhost:5173`). Откройте его в браузере.

### 3. Сборка production-версии

```bash
npm run build
```

Готовые статические файлы будут сгенерированы в папку `dist/`.

> **Важно о Vite:** В файле `vite.config.ts` уже настроен параметр `base: './'`. Благодаря этому все пути к скриптам и стилям являются относительными, и сайт гарантированно откроется в любом подкаталоге GitHub Pages без белого экрана.

---

### 4. Создание GitHub-репозитория

1. Зайдите на [github.com](https://github.com/) и войдите в свой аккаунт.
2. В правом верхнем углу нажмите кнопку **+** → **New repository**.
3. Укажите название репозитория (например, `my-shifts` или `shift-tracker`).
4. Выберите **Public** (публичный) и нажмите **Create repository**.

---

### 6. Включение GitHub Pages

Самый простой и надёжный способ публикации Vite-приложения на GitHub Pages — использование готового **GitHub Actions**:

1. В репозитории на GitHub перейдите во вкладку **Settings** (Настройки).
2. В левом меню выберите раздел **Pages**.
3. В выпадающем списке **Source** (Источник) выберите:
   * **GitHub Actions**
4. Ниже нажмите кнопку **Configure** рядом с шаблоном **Static HTML** (или создайте файл `.github/workflows/deploy.yml` со следующим содержимым):

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: ['main']
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: 'pages'
  cancel-in-progress: true

jobs:
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Set up Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Build
        run: npm run build

      - name: Setup Pages
        uses: actions/configure-pages@v4

      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'

      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

5. Нажмите **Commit changes...** (Зафиксировать изменения).

---

### 7. Получение публичной ссылки на сайт

После того как GitHub Action завершит сборку (обычно 1–2 минуты):
1. Перейдите во вкладку **Actions** в репозитории и убедитесь, что сборка отмечена зелёной галочкой.
2. Перейдите в **Settings** → **Pages**.
3. Вверху появится блок с готовой публичной ссылкой вида:
   ```
   https://ВАШ_АККАУНТ.github.io/my-shifts/
   ```
4. Откройте ссылку на компьютере или на смартфоне — приложение сразу готово к работе!
